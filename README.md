# lets - Task Library Demo

This is a companion template to [`lets`](https://github.com/JeffDess/lets) to
demonstrate how to publish your own task libraries.

![Diagram of flake composition for your task library](https://github.com/JeffDess/lets/raw/main/img/task_library.svg)

For more information, refer to the [documentation about sharing tasks across projects](https://github.com/JeffDess/lets#sharing-tasks-across-projects)
You will find here a template to help your own [flake](./flake.nix) for your library.
